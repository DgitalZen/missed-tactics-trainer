# Changelog

## 0.1.0 (first public release)
- Analyse games from a PGN file or a Lichess account and turn missed mates, missed wins, blunders and mistakes into puzzles.
- "Is there a tactic here?" step with quiet positions, so you practise reading the board without a cue.
- Trainer page: line play, free exploration, hints, try-again, timed rounds, filters, notes and tags, stats, progress export/import.
- Pattern tags: forks, pins, skewers, discovered attacks, hanging pieces, and several mate patterns.
- Local server mode with live Stockfish arrows and evaluations.
- Early release: expect rough edges. Please report problems as issues.
